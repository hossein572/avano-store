# آوانو — فروشگاه اینترنتی مد و اکسسوری زنانه

یک نمونه‌کار فروشگاهی کاملاً فارسی و راست‌به‌چپ با طراحی editorial و تجربه خرید تعاملی. پروژه با React، TypeScript، Vite، Tailwind CSS و React Router ساخته شده و بدون بک‌اند واقعی قابل اجرا و انتشار است.

## راه‌اندازی

```bash
npm install
npm run dev
```

برای خروجی انتشار:

```bash
npm run build
npm run preview
```

پوشه `dist` خروجی آماده انتشار روی سرویس‌های میزبانی است. برای مسیریابی در انتشار، بازنویسی تمام مسیرها به `index.html` را فعال کنید.

## امکانات

- ۲۴ محصول نمونه در ۴ دسته با تصاویر محلی، تخفیف، موجودی، امتیاز و تصاویر جزئیات
- صفحه خانه، فروشگاه با فیلتر و مرتب‌سازی، جزئیات محصول، جستجو، علاقه‌مندی‌ها و حساب کاربری
- سبد خرید، انتخاب رنگ و سایز، راهنمای سایز، فرم ثبت سفارش و صفحه موفقیت نمایشی
- نگهداری سبد خرید و علاقه‌مندی‌ها در `localStorage`
- تصاویر editorial و تصاویر جداشده از پس‌زمینه برای کیف و کفش؛ فونت فارسی به‌صورت محلی

این پروژه یک دموی نمونه‌کار است؛ پرداخت، ارسال پیامک و ذخیره سفارش واقعی ندارد. تصاویر محصولات صرفاً برای نمایش طراحی نمونه استفاده شده‌اند.
